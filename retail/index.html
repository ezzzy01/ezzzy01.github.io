Why it was built

The numbers were there. Getting them wasn’t easy.

01

Reports took a person

A question like “how much did we sell last week, up to 2 pm today?” meant someone pulling a report from the ERP.

Ask it in a sentence and get the answer, a chart and the table in about a second.

02

Cloud AI was off the table

Sales, margins and supplier prices are sensitive. Sending them to an online AI service wasn’t an option.

The AI model, the database and the automations all run on the company’s own hardware.

03

AI answers can drift

Ask a chatbot the same thing twice and the numbers or the format can change.

Every number comes straight from the ERP, so the same question gives the same numbers every time.

What it does

One place for the shop’s numbers.

Built the way a shop would use it: a dashboard first, questions when you need them, and a daily summary that arrives by itself.

Ask, and see how it was answered

Type a question in English or Malay. Each answer shows which report was used, a one-line summary, a chart and the full table.

  • About a second per answer on a gaming graphics card
  • Questions outside sales, stock and purchasing are politely refused
  • Download any answer as CSV or a report page

Roles

The right view for each person

Management sees every branch. A branch manager only sees their own branch, even when asking in plain language. Purchasing gets a stock-first view.

Automation

A daily report, no AI needed

Every morning a summary of yesterday arrives on Telegram or WhatsApp, with the full report attached. Approved people can also ask questions from their phone.

Control

Every request on record

Sign-in, account lock-out after repeated wrong passwords, and an audit log of who asked what and which report answered.

Questions

Good to know.

Is this made by or for Brightstar?

No. It’s an unofficial mock demo I made on my own, using the Brightstar name and logo only to show the idea in context. It isn’t affiliated with or endorsed by Brightstar Computer, and every branch, person and number is made up.

Can I try it?

It runs on my own PC, because the AI model and the data are local by design, so there’s no public demo. I’m happy to show it live on a call.

Does the AI make up numbers?

No. Every number on screen comes from the ERP data, and the same question always gives the same numbers.

Why not use ChatGPT or another online AI?

Because the shop’s sales and supplier data shouldn’t leave the company. A local model keeps everything on site.

What hardware does it need?

A PC with a gaming graphics card is enough, and a dedicated AI machine runs the larger models. The benchmark page shows which models fit which hardware.

Can I see the source code?

No, the code is private. I’m happy to show it running on a call.

Want to see it answer live?

I can run it on a call: ask your own questions about the mock shop and see the answers arrive.
